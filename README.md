# اقرأ القرآن الكريم

قارئ مصحف على الويب يعرض الصفحة مطابقة للمصحف المطبوع (مصحف المدينة، حفص)، ويفتح مشروعات المحتوى عند لمس الكلمة أو رأس الآية أو ترويسة السورة أو رقم الصفحة. صفحة واحدة على الجوال وصفحتان على اللوحي.

**التطبيق:** [ashamsitqan.github.io/iqra-quran-app](https://ashamsitqan.github.io/iqra-quran-app/) — تطبيق ويب يُثبَّت على الجوال والحاسب، غير ربحي، ونسخته تجريبية.

## ما فيه

- **المصحف:** ثلاث طرق عرض (مطابق للمطبوع، تكبير وتصغير النص، آية وتفسير)، فهرس وبحث، وضع ليلي ونهاري، علامات الأرباع والسجدات ومواضع الركوع.
- **المحتوى:** تفاسير ومعانٍ وغريب وإعراب وصرف وقراءات ومتشابهات، على مستوى الكلمة والآية والصفحة والسورة، مع التفصيل الموضوعي.
- **الحفظ:** ملقّن بطريقة التكرار الدائري المتقاطع على التلاوات المزمَّنة.
- **التسميع:** يسمع القارئ ويتابعه على الصفحة، بحزمة TajweedFormer من Quran Lab، مع سجل للنشاط.
- **بياناتي:** علامات وتعليقات، نسخ احتياطي، مزامنة Google Drive، والعمل دون اتصال للمحتوى المنزَّل.
- **المشاركة:** الآية برسم المصحف فوق النص، صورةً أو PDF نصيًّا أو نصًّا.

## مكوّن «تكرار»

طريقة التكرار الدائري المتقاطع مستخرجة من التطبيق مكوّنًا مستقلًا في مجلد [`tikrar/`](tikrar/)، يستطيع أي صاحب تطبيق قرآني
أن يضعه في تطبيقه. هو منطق فقط (بلا واجهة ولا مشغّل صوت)، بست لغات: JavaScript/TypeScript و Dart و Kotlin و Swift و C#‎ و Python،
وكلها تجتاز ملف اختبارات واحدًا. يعمل مع التلاوات المزمَّنة على مستوى الكلمة والجملة والآية، والتلقين فيه للآيات وللجمل على حدّ سواء.

- الشرح والاستعمال: [`tikrar/README.md`](tikrar/README.md) · المواصفة: [`tikrar/SPEC.md`](tikrar/SPEC.md)
- صفحة التجربة: [ashamsitqan.github.io/iqra-quran-app/tikrar/demo](https://ashamsitqan.github.io/iqra-quran-app/tikrar/demo/)
- موضوع الفكرة: [community.itqan.dev/d/432](https://community.itqan.dev/d/432)

## التشغيل محليًا

```
./scripts/fetch-pages.sh          # ينزّل صفحات المصحف من quran.ws ويبني الفهارس (نحو 108 م.ب)
python3 -m http.server -d public  # ثم افتح http://localhost:8000
```

## البنية

| المسار | المحتوى |
|---|---|
| `public/index.html` | التطبيق كله (واجهة وشيفرة) |
| `public/data/projects.json` | قائمة المشروعات ومستوى كل منها (كلمة، آية، صفحة، سورة) |
| `public/content/` | محتوى المشروعات (يُبنى، لا يُحفظ في المستودع) |
| `public/pages/` | صفحات المصحف SVG (تُنزَّل، لا تُحفظ في المستودع) |
| `scripts/` | تنزيل الصفحات وبناء الفهارس |
| `public/engine.js` | محرّك مواضع المراجعة في التسميع، بحسب مواصفة Quran Lab |
| `tikrar/` | مكوّن التكرار الدائري المتقاطع المستقل |
| `tests/` | اختبارات المحرّك وفحص سلامة كود التطبيق قبل النشر |
| `itqan-assets.yaml` | أصول فنار التي يسحبها `itqan-cli` |

## إضافة مشروع محتوى

1. أضف سطرًا في `public/data/projects.json` يحدد الاسم والمستوى ومسار الملف.
2. ضع ملف JSON مفتاحه `سورة:آية:كلمة` (كلمة) أو `سورة:آية` (آية) أو رقم السورة أو رقم الصفحة.
   لمستويي الكلمة والآية يُقسَّم الملف على الصفحات: `content/<المشروع>/{page}.json`.

المشروعات التي قيمة `file` فيها `null` أماكن محجوزة لم تُربط بعد.

## المصادر والتراخيص

- صفحات المصحف: [quran-ws/quran-svg-elements](https://github.com/quran-ws/quran-svg-elements). الفهارس برخصة CC BY 4.0. رسم الصفحات ونص المصحف لمجمع الملك فهد لطباعة المصحف الشريف، ويلزم الاستئذان قبل إعادة نشرها علنًا.
- محتوى فنار: كل أصل برخصته المذكورة في cms.itqan.dev (أغلبها CC BY-ND أو CC BY-NC-ND).
- الإعراب والصرف والقراءات: الواجهة البرمجية العامة لموقع سورة.
- المتشابهات ومواضع الركوع: [QUL](https://qul.tarteel.ai) من ترتيل.
- التسميع: حزمة TajweedFormer من [Quran Lab](https://quranlab.ai) برخصتها (غير ربحي، ولا يُعرض ناتجها حكمًا شرعيًّا).

## المتبقي

- اختبار التسميع بأصوات حقيقية متنوعة؛ وهو لا يفحص المد ولا الشدة ولا الغنة في هذه النسخة.
- تزمين الكلمات والجمل متوفر لتلاوة واحدة لسورة البقرة؛ التلقين على مستوى الجملة ينتظر بقية التلاوات.
- التلاوات لا تعمل دون اتصال، وتلوين أحكام التجويد مؤجَّل.
- مزامنة Google Drive في وضع الاختبار لمستخدمين محددين.
- لا نسخة في متاجر التطبيقات بعد.
- مراجعة التراخيص والاستئذان من أصحاب المصادر قبل أي إطلاق عام، وتحديد ترخيص مكوّن «تكرار».
